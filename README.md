## 👨‍💻 About Me

I'm an early-career software engineer working on full-stack and AI-powered applications. I graduated in Computer Science & Engineering from AIUB, started as a software engineering intern in June 2026 and now work full-time as a Software Engineer.

At work I build frontend features, backend APIs and agent workflows, mostly with TypeScript, Next.js, Python, FastAPI and PostgreSQL. So far that has included agentic chat features with tool calling, knowledge retrieval, document processing and sandboxed code execution.

I'm still learning a lot and I like understanding how things work under the hood rather than only making them work.
