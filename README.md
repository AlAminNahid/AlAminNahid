## 👨‍💻 About Me

I'm a Software Engineer working across full-stack development and applied AI, building production applications from frontend interfaces to backend services and AI-powered workflows.

My experience includes developing agentic systems with custom Python orchestration, tool calling, multi-step workflows, and conversational state management. I've also worked on custom knowledge retrieval systems, document-processing pipelines, collaborative editing, and sandboxed code execution.

I primarily work with TypeScript, Next.js, Python, FastAPI, NestJS, ASP.NET Core Web API, and PostgreSQL, with experience deploying applications using Google Cloud Run.

My broader interests include LLM engineering, backend architecture, machine learning, and building reliable software that solves real-world problems.
